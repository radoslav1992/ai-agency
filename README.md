# AIA

Двуезичен сайт на **AIA** — AI агенция за автоматизация на бизнес процеси.
**Българският е основният език и стои на корена** (`/`), английският е
вторичен и живее под `/en/`. Дизайнът е шаблонът **AI Creative Studio /
Optim AI**, попълнен със съдържание за AI агенция.

## Обхват

Сайтът говори само за AI и автоматизации: готови агенти за телефон, чат, поща
и документи, автоматизация на повтарящи се процеси, AI върху фирмени документи,
свързване със съществуващи системи и обучение на екипа. Портфолио, блог и
услуги извън AI нарочно ги няма.

| Български | Английски |
| --- | --- |
| `/` | `/en/` |
| `/agents/` | `/en/agents/` |
| `/contact/` | `/en/contact/` |
| `/terms/`, `/privacy/`, `/cookies/` | `/en/terms/`, `/en/privacy/`, `/en/cookies/` |

## Стек

| Какво | Защо |
| --- | --- |
| [Astro 5](https://astro.build) | статичен изход, вградено `i18n` рутиране, оптимизация на изображенията |
| [Tailwind CSS v4](https://tailwindcss.com) | `@theme` блокът в `src/styles/global.css` възпроизвежда точките на шаблона |
| `@fontsource-variable/*` | шрифтовете се сервират от домейна, без заявка към Google Fonts |
| GSAP + `public/vendor/template.js` | анимационният двигател на шаблона, както е в оригинала |
| `@astrojs/cloudflare` + Wrangler | пускане като Worker със статични файлове |

```bash
npm install
npm run dev      # http://localhost:4321
npm run check    # astro check — типове и разметка
npm run build    # dist/
npm run preview  # astro build + wrangler dev — както е на Cloudflare
npm run deploy   # astro build + wrangler deploy
```

## ⚠️ Запълващи стойности

Тези неща са поставени, за да работи сайтът, но НЕ са истински. Сменете ги,
преди да тръгне в производство:

| Къде | Какво |
| --- | --- |
| `src/data/site.mjs` → `url` | `https://aia.bg` — от него се раждат canonical, hreflang, og:url и картата на сайта |
| `src/data/site.mjs` → `email` | `hello@aia.bg` |
| `src/data/site.mjs` → `legalName` | „AIA“ — сменете с регистрираното дружество и ЕИК |
| `src/data/content.ts` → `PLANS` | цените в трите пакета |
| `wrangler.jsonc` → `send_email`, `vars` | адресите за доставка на формата |

## Съдържание

Текстовете са данни, не разметка. Редактират се в `src/data/`:

| Файл | Какво съдържа |
| --- | --- |
| `site.mjs` | име, домейн, контакти, навигация, локация по език |
| `content.ts` / `content.en.ts` | услуги, процес, условия, пакети, лентата „защо“, интеграции, опции във формата |
| `agents.ts` / `agents.en.ts` | каталогът с готовите AI агенти |

Правилото, което държи текста честен: **тук не се пише резултат, който не е
измерен при клиент.** Няма отзиви, няма проценти, няма „500+ клиенти“. Копието
описва какво прави системата, не какво е постигнала. Ако добавите отзив или
число, то трябва да е проверимо.

## Изображения

- **Рисунките на агентите** (`src/assets/agents/`) са единствените илюстрации.
  Търсят се по `id` на агента през `src/data/agentShots.ts`.
- **Логата на интеграциите** (`public/images/icons/`) идват с шаблона —
  единствените истински картинки в него. Останалите му изображения са сиви
  правоъгълници с размери и затова не се ползват.
- **Градиентите и диагоналната форма** (`public/images/gradient/`,
  `public/images/shape/`) също идват от шаблона; PNG-тата са преобразувани в
  WebP (12 MB → 0.85 MB).
- **Знакът на AIA** е `public/images/logo/aia-mark.svg`; от него са
  генерирани иконите и `og.png`.

Анимацията `data-client-reveal` на шаблона нарочно НЕ се ползва за
интеграциите: тя подменя иконите на случаен принцип от общ пул и показва едно
и също лого на две места. При измислени лога това е ефект; при истински —
грешка.

## Двуезичие

`astro.config.mjs` задава `defaultLocale: 'bg'` с `prefixDefaultLocale: false`,
затова българските адреси нямат префикс, а английските получават `/en`.

- `src/i18n/index.ts` — езикът на страницата, адресът на същата страница на
  другия език, `hreflang` двойките.
- `src/i18n/ui.ts` — надписите по компонентите.
- `src/i18n/pages.ts` — заглавията и уводите на вътрешните страници.
- `src/i18n/content.ts` — кой набор данни отива с кой език.

Българският е на „вие“: AIA е агенция, а не един човек.

## Типография и кирилица

Sora, шрифтът на заглавията в шаблона, **няма кирилица**. Затова на
българските страници `--font-sora` сочи към **Manrope**, който има и двете
азбуки — иначе заглавие като „AI агенти“ се изписва с два шрифта в един ред.
Английските страници остават със Sora. `font-feature-settings: 'locl' 0`
изключва българските форми на кирилицата, защото Manrope ги има, а Inter Tight
в текста — не. Всичко това е в `src/styles/global.css`.

## Формата за контакт

`src/pages/api/contact.ts` е единственият маршрут, който не се компилира
предварително (`export const prerender = false`) — работи във Worker-а и
изпраща писмото през **Cloudflare Email Routing**, без външна услуга и без
ключ за API. Валидацията е и от страна на сървъра, съобщенията са на езика на
формата, капанът за ботове връща „изпратено“ и изхвърля писмото, а `Reply-To`
е адресът на подателя. Без JavaScript формата работи като обикновен `POST` и
Worker-ът връща 303 към `/contact/?sent=1`.

## Пускане на Cloudflare

Сайтът се качва като **Worker със статични файлове**: цялото `dist/` става
статика, а до кода стига единствено `/api/contact`.

`public/.assetsignore` изважда `_worker.js` и `_routes.json` от статиката —
без него Wrangler отказва цялото качване.

Преди първото пускане:

1. **Email Routing** — включете го за зоната на домейна и потвърдете адреса
   получател. Той трябва да съвпада едновременно с
   `send_email.destination_address` и с `vars.CONTACT_TO`.
2. **Подател** — `vars.CONTACT_FROM` трябва да е адрес в зона от същия акаунт
   с включен Email Routing.
3. **Домейн** — добавете потребителски домейн на Worker-а и сменете `SITE.url`.
4. **Аналитика** — `SITE.gaId` е `null`, тоест аналитика и банер за бисквитки
   няма. Сложите ли ID, банерът се появява сам, а текстът на `/cookies/` трябва
   да се върне към варианта, който описва Google Analytics като активен.

`public/_headers` задава `Cache-Control: immutable` за хешираните файлове в
`/_astro/`, плюс `nosniff`, `Referrer-Policy`, `X-Frame-Options`,
`Permissions-Policy` и HSTS.
